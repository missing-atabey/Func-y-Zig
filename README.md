# Func-y-Zig
Making Zig unnecessarily haskell-shaped since 2026 🦎λ

## Summary
This library simply adds a bunch of that nonsensical functional yumminess from Haskell to our beloved Zig

the goal is to allow for simple and concise functional operations while still remaining speedy in the situations that need it. The implementations may not be pure in a functional sense but they help bridge the gap between short, concise, and functional, and procedural and more elaborate code.
